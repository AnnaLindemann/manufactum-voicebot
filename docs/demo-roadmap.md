# Demo Roadmap

## Purpose

Development is organized around demonstrable milestones.

Each milestone delivers a working capability that can be presented to the customer for feedback before continuing with the next stage.

---

# Milestone 1 — Product Search Voicebot

Goal

Demonstrate a working AI Voicebot connected to the Manufactum API.

Includes:

- API Discovery
- Backend API Client
- Product Search
- Product Selection
- Price Retrieval
- Availability Lookup
- Store Availability (if supported)
- Online Availability (if supported)
- Alternative Products (if supported)
- Human Transfer
- Cost Measurement

Deliverable

A working Dialfire Voicebot capable of searching products using the real API.

Customer Review

Present the working bot to Ralph.

Collect feedback before expanding functionality.

---

# Milestone 2 — Reservation & Store Services

Possible scope:

- Reservation
- Reservation Lookup
- Reservation Cancellation
- Advanced Store Search
- PLZ / City Search
- Improved conversation flows

Deliverable

Second working demo.

Customer Review

Validate workflow with Ralph.

---

# Milestone 3 — Website RAG

Goal

Extend the assistant with knowledge retrieved from the Manufactum website.

Includes:

- Website ingestion
- Versioned documents
- Versioned chunks
- Embeddings
- Vector Search
- FAQ
- Delivery
- Returns
- Payment
- Customer Service

Deliverable

Voicebot answering FAQ using RAG.

Customer Review

Validate answer quality and retrieval accuracy.

---

# Milestone 4 — Customer Communication

Possible scope:

- Email
- SMS
- WhatsApp
- Product Links
- Store Links

Deliverable

End-to-end customer communication.

---

# Principle

Do not implement all planned functionality before showing results.

Each milestone should produce a usable demonstration, receive customer feedback, and only then continue with the next milestone.
