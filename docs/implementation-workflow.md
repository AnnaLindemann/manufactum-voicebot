# Implementation Workflow

## Principle

Implement one roadmap phase at a time.

## Sequence

1. Read frozen documentation.
2. Confirm phase scope.
3. Implement only that phase.
4. Run tests.
5. Write implementation report.
6. Perform architecture review.
7. Fix findings.
8. Accept phase.
9. Move to the next phase.

## Scope examples

- no Supabase during API discovery;
- no RAG before source registry;
- no reservation flow before reservation API discovery;
- no WhatsApp integration before channel requirements are approved.

## Required phase report

- files changed;
- functionality added;
- tests executed;
- results;
- assumptions;
- unresolved questions;
- limitations;
- documentation updates;
- recommendation for next phase.
